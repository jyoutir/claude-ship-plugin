# Commit Message Standards

## Format
- Line 1: What changed (max 50 chars, imperative mood)
- Line 2: Why (optional, if context needed)

## Examples
```
Add character persona selection
Fix WebRTC connection timeout on slow networks
Update session timer to support pause/skip
```

## Style
- Use imperative mood: "Add", "Fix", "Update", "Remove"
- No period at end
- Be specific but concise
